# Task execution baseline

1. Read the task instruction carefully; identify the deliverable and how it will be checked.
2. Inspect the environment before acting: `ls`, `cat` relevant files, check available tools (`command -v`).
3. Form a short plan, then execute it step by step with the bash tool.
4. After each significant step, verify the effect (rerun the relevant check, inspect output files).
5. Before finishing, re-read the task statement and confirm every requirement is met.
